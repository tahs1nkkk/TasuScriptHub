```luau
assert(loadstring(game:HttpGet("https://raw.githubusercontent.com/tahs1nkkk/TasuScriptHub/refs/heads/main/loader.lua")))()
```

## MM2 Discord live card

`loader.lua`, Murder Mystery 2 icinde calistiginda bilgisayardaki loopback servisten telemetry modulunu otomatik yukler. Discord bot tokeni Roblox koduna gomulmez.

1. `discord-live-card` klasorune girin.
2. `.env.example` dosyasini `.env` olarak kopyalayip yerel ayarlari doldurun.
3. `npm install` ve ardindan `npm start` calistirin; Windows'ta `start-local.cmd` de kullanilabilir.
4. MM2 icinde yukaridaki loader'i calistirin.

Ayrintilar icin [Discord live card kilavuzuna](discord-live-card/README.md) bakin.
