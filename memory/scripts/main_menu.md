Role: contract-version-1 remote controller for the general TasuHub window launched by corner-action slot 2. It owns presentation, category navigation, search results, page transitions, window dragging, and view-scoped control connections only. Gameplay engines and persistent state remain loader/controller owned.

The window opens/closes from the live center of slot 2 and remains clamped to the viewport while dragged from non-control header space.

The page host simultaneously expands leftward from the right and recenters its content. Expanding reverses the same geometry without reconstructing feature engines.

Only the selected page tree exists. Category change disconnects the previous page's scoped inputs, animates the old page upward while fading out, constructs the new page 28 px above its resting position, fades/slides it down, and destroys the prior page after its exit token. Controls are grouped by stable `Category/Section/Label` descriptors. Visible toggle, slider, dropdown/player selector, input, and action views call loader-owned `Get`/`Set`/`Activate` controller methods; they never mutate gameplay state directly. Hidden legacy instances remain presentation-inert and are used only as temporary controller registration owners until later physical migration.

Search consumes copied stable descriptors rather than UI descendants. Results include categories and indexed controls, navigate to the correct category, rebuild only that page, scroll to the target row, and briefly highlight it. The result list owns a separate scoped connection bucket cleared on every query rebuild.

Lifecycle: persistent shell connections belong to the controller/global tracker. Page and search-result connections are independently disconnected before their trees are replaced. Transition/page/search revisions reject stale completion. `Destroy` invalidates revisions, stops slider/drag ownership, disconnects all buckets, and destroys `MainMenuRoot`.
