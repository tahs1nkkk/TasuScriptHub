# Script memory: main_menu.lua

Role: contract-version-2 remote controller for the general TasuHub window launched by corner-action slot 2. It owns presentation, category navigation, search/results, shared dropdowns, page transitions, responsive scaling, window/overlay dragging, and view-scoped connections only. Gameplay engines and persistent state remain loader/controller owned.

Revision 2 uses a 780×520 base window, 20 px outer radius, 60 px opaque `Base` header, 0.20-transparent `Layer` body, shared search geometry, shared open/close motion, and no footer. One `UIScale` scales the complete tree down on small screens. Dragging is intentionally unclamped; reopening recenters only when less than 50% of the scaled bounds remain visible.

The left navigation is expanded by default at 230 px. Nine buttons expose `Home`, `Players`, `Visuals`, `Aim`, `Movement`, `World`, `Lighting`, `Misc`, and `Configs`. The three-line control lives in the rail's fixed top region. Buttons keep one fixed size while the rail, icon position, label position/transparency, and page host animate to/from 72 px. Icons come from the loader's central link resolver and fall back to built-in glyphs after missing/failed loads.

Only the selected page tree exists. Category change disconnects scoped inputs, completes the old page's upward fade, waits 0.3 seconds, then creates/reveals the new page; revision tokens reject stale rapid selections. Sections are balanced between two independent columns and start expanded. Arrow-controlled collapse animates height and group opacity and persists for the session. Players is full width and uses twelve recycled rows around the visible scroll window. Controls call loader-owned contracts; list controls open one shared true selection popup.

The right header reuses the catalog search language. Search consumes copied registration-ordered descriptors rather than UI descendants and presents category, section, then control levels with distinct shared-theme hierarchy. Selection opens the owning card, scrolls/highlights the control, clears/releases the textbox, and closes the search shell. Real dropdown and result controls own separate scoped connection buckets.

The full-width Players page consumes `player_service.lua` snapshots/actions and preserves avatar, display/username, relation, distance, health, View, TP, Fling, and Walk/Stop. The draggable `Live Stats` overlay consumes only loader snapshots; closing it writes the existing Show Stats controller flag.

Lifecycle: persistent shell connections belong to the controller/global tracker. Page and search-result connections are independently disconnected before their trees are replaced. Transition/page/search revisions reject stale completion. `Destroy` invalidates revisions, stops slider/drag ownership, disconnects all buckets, and destroys `MainMenuRoot`. Loader destroys this controller before the catalog and root sweep. No Studio path exists.

Loader boundary: the callback/context adapter that downloads and creates this module must remain inside its dedicated function scope. Moving its helper functions back into `loader.lua`'s outer frame can exceed the executor Luau compiler's 200-local-register limit before this module is downloaded.
