# Script memory: main_menu.lua

Role: contract-version-2 remote controller for the general TasuHub window launched by corner-action slot 2. It owns presentation, category navigation, search/results, shared dropdowns, page transitions, responsive scaling, window/overlay dragging, and view-scoped connections only. Gameplay engines and persistent state remain loader/controller owned.

Revision 2 uses a 780×520 base window, 20 px outer radius, 60 px opaque `Base` header, 0.20-transparent `Layer` body, shared search geometry, shared open/close motion, and no footer. One `UIScale` scales the complete tree down on small screens. Dragging is intentionally unclamped; reopening recenters only when less than 50% of the scaled bounds remain visible.

The left navigation is expanded by default at 230 px. Ten buttons expose `Home`, `Players`, `Visuals`, `Aim`, `Movement`, `World`, `Lighting`, `Waypoints`, `Misc`, and `Configs`. The three-line control lives in the rail's fixed top region. Buttons keep one fixed size while the rail, icon position, label position/transparency, and page host animate to/from 72 px. Icons come from the loader's central link resolver and fall back to built-in glyphs after missing/failed loads.

Only the selected page tree exists while the window is open. Category change disconnects scoped inputs, completes the old page's upward fade, waits 0.22 seconds, then creates/reveals the new page; revision tokens reject stale rapid selections. A revision-valid close completion disconnects the page bucket and destroys the active page so the closed window retains only its lightweight shell and descriptor metadata; reopening constructs the selected page again. Sections are balanced between two independent columns and start expanded. The disclosure glyph is `<`, rotated down/up by state. A page containing one section expands that section and balances its controls across two internal columns. Arrow-controlled collapse animates height and group opacity and persists for the session. Players is full width and uses twelve recycled rows around the visible scroll window. Controls call loader-owned contracts; list controls open one shared true selection popup.

The right header reuses the catalog search language. Search consumes copied registration-ordered descriptors rather than UI descendants and presents category, section, then control levels with distinct shared-theme hierarchy. Selection opens the owning card, scrolls/highlights the control, clears/releases the textbox, and closes the search shell. Real dropdown and result controls own separate scoped connection buckets.

The full-width Players page consumes `player_service.lua` snapshots/actions and preserves avatar, display/username, relation, distance, health, View, TP, Fling, and Walk/Stop. Player actions show only centrally resolved state-aware icons with glyph fallback; no action text is rendered. The draggable `Live Stats` overlay consumes only loader snapshots; closing it writes the existing Show Stats controller flag.

Home displays measured loader duration with the shared success/warning/danger thresholds and places one full-width two-second hold-to-unload surface after all Home content. Its red fill uses the outer 14 px radius; its white theme-token grid loops seamlessly toward the upper-right only while held. Rising checkpoint audio, cancellation reversal, and final unload request are presentation owned; the loader remains lifecycle authority.

Every toggle descriptor with a stable `BindId` receives the compact shared bind control. Search selection opens the destination section, scrolls to the row, and inverts its shared surface/text colors three times before restoring the exact captured colors and releasing the temporary stroke.

Lifecycle: persistent shell connections belong to the controller/global tracker. Page and search-result connections are independently disconnected before their trees are replaced. Transition/page/search revisions reject stale completion. `Destroy` invalidates revisions, stops slider/drag ownership, disconnects all buckets, and destroys `MainMenuRoot`. Loader destroys this controller before the catalog and root sweep. No Studio path exists.

Loader boundary: the callback/context adapter that downloads and creates this module must remain inside its dedicated function scope. Moving its helper functions back into `loader.lua`'s outer frame can exceed the executor Luau compiler's 200-local-register limit before this module is downloaded.

Comfort-scale correction: the 780×520 design canvas is preserved while the entire window tree renders through the shared `WorkspaceScale` cap (`0.86`) or a lower responsive fit. This keeps the two-column/card geometry intact while preventing oversized controls and edge overflow.
