# Script memory: game_catalog.lua

Role: versioned remote UI module for the reworked game/script catalog.

The module returns a frozen contract-version-1 table with one `Create(context)` factory. It is fetched from the `codex/ui-rework` raw GitHub branch and compiled only through executor `loadstring`; it is never adapted for Roblox Studio and has no embedded fallback inside `loader.lua`.

The factory receives `InterfaceRoot`, the shared `Base`/`Layer`/`Signal` plus semantic `Success`/`Warning`/`Danger` colors, shared Nunito/BuilderSans fonts, all catalog layout/motion tokens, input/audio/lifecycle services, live anchor/viewport providers, a copied catalog-entry provider, and loader-owned execution/cover services. It constructs one hidden `GameCatalogRoot` and returns a frozen controller exposing only `Open`, `Close`, `Toggle`, `IsOpen`, and `Destroy`. It contains no private palette, font, duration, or layout registry.

Revision-2 composition: responsive maximum 780×520 popup; opaque 60 px header and 42 px footer; 20%-transparent middle body; centered `Oyun Kataloğu` title; right search and close controls; hover-revealed clipped local search input with the result count immediately to its right; vertically scrolling three-column grid; 238 px cards with a 142 px automatic Roblox cover, a colored 26 px status strip inside the cover's bottom edge, larger name, and centered-dot feature summary. Run hints and static footer explanations are removed. Header and footer drag zones update a viewport-clamped resting position.

The official status and feature maps are private and frozen. MM2 is `Stable`; entries without a remote built-in mapping receive remote default `Supported`; entry-provided `Status` and `Features` fields are discarded. No setter or map is returned. Five remote-owned non-executable previews fill the second layout row and resolve real-game covers. Preview and `Un-Supported` cards never call the execution service.

Open/close now uses a revision-guarded fixed-layout origin transition. The window keeps its final pixel size, begins at the upper button's sampled center with whole-window scale 0, and moves to its saved center while scaling to 1. Close re-samples the button, moves there, and reaches scale 0 before hiding. No child size changes or reflows during the transition. Search and cover continuations verify ownership/destroyed state.

Card hover uses the shared yellow `Warning` outline. An unavailable or failed activation changes the outline to `Danger`, shakes only the card inside its layout slot, and shows a bottom-center red reason toast. Successful execution uses `Success` outline/toast without the failure shake. Outcome delays are revision-guarded so repeated clicks cannot let an older completion clear newer feedback.

Executor acceptance: verify remote fetch/compile/version, one-controller ownership, all four dock anchor paths, scale reaches exact 0/1 without content reflow, interruption/re-entry, current-position close targeting, header/footer drag and viewport clamp, exact opaque/20%-transparent regions, responsive three-column scrolling, hover/pinned/empty search behavior and count placement, six cover success/fallback paths, immutable displayed metadata despite entry fields, all three status colors, yellow hover glow, failure shake/red toast, success green toast, MM2 place rejection, duplicate run rejection, and complete unload cleanup.
