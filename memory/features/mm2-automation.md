# Feature memory: MM2 pickup and fire automation

State: MM2 `AutoPickup`, `AutoFire`, `AutoFarm`, `FarmSpeed`; manual pickup/fire actions share the same service. Compatibility snapshots still expose `UndergroundOffset`, but revision 3 fixes it at exactly `7 studs` and rejects all other runtime/config values by normalizing them to 7. The UI no longer exposes an offset slider.

Behavior: pickup uses prompt/touch helpers. Shooting equips Gun, predicts murderer position, sets a bounded silent-target record, and activates the real Gun Tool. A service-owned `__namecall` interceptor rewrites only the target-position argument when the game's own controller invokes `ShootGun`; this preserves the live game's other arguments. The old direct `(1, position, "AH")` request is fallback-only. Auto Fire additionally requires viewport and physical raycast visibility and has a 0.75-second cooldown.

Farm caches the active-map `CoinContainer`, enumerates only its direct collectible children, stays exactly 7 studs below the target, travels at constant speed with 30 Hz noclip movement, and sends a double touch pulse to the BasePart that owns `TouchTransmitter`. Removal/transparency/bag-count acknowledgement lasts at most roughly 0.2 seconds; an unconfirmed target is skipped for 0.8 seconds and discovery refreshes after five failures. Capacity is scoped to the CoinBags UI with a fallback of 50. At full capacity, farm restores its character mutations, resets the character, waits AFK until the old round/map has ended, then waits for a new map with live collectibles and a reset bag before resuming automatically.

Executor checks: helper present/missing, Gun absent/equipped/backpack, murderer absent/visible/occluded, game-owned `ShootGun` call observation, compatibility fallback, cooldown, decompiler diagnostic output in each local role, lobby/preparing/active phase reporting, invariant 7-stud offset, 50-capacity and explicit-capacity bag HUD variants, multiple maps, no collectibles, fast target-to-target cycling, touch-part correctness, skip expiry/cache refresh, full-bag reset, old-round AFK, next-round automatic resume, sustained frame time, death/respawn, manual stop, hub unload, and re-execution. Failed paths report failure and never claim confirmed game-controller firing.
