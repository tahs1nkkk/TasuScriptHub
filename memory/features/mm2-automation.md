# Feature memory: MM2 pickup and fire automation

State: MM2 `AutoPickup`, `AutoFire`, `AutoFarm`, `FarmSpeed`, `UndergroundOffset`; manual pickup/fire actions share the same service.

Behavior: pickup uses prompt/touch helpers. Shooting equips Gun, predicts murderer position, sets a bounded silent-target record, and activates the real Gun Tool. A service-owned `__namecall` interceptor rewrites only the target-position argument when the game's own controller invokes `ShootGun`; this preserves the live game's other arguments. The old direct `(1, position, "AH")` request is fallback-only. Auto Fire additionally requires viewport and physical raycast visibility and has a 0.75-second cooldown.

Farm caches the active-map `CoinContainer`, enumerates only its direct collectible children, sinks to the configured offset, travels at constant speed with 30 Hz noclip movement, fires executor touch without surfacing, and acknowledges removal/transparency/bag-count changes. It retries twice per item, skips a failed item for three seconds, and refreshes discovery after five failures rather than selecting the same dead target forever. Bag-full handling shoots as Sheriff, uses Knife/touch as Murderer, and waits as Innocent; lobby/round polling continues while enabled.

Executor checks: helper present/missing, Gun absent/equipped/backpack, murderer absent/visible/occluded, game-owned `ShootGun` call observation, compatibility fallback, cooldown, decompiler diagnostic output, seasonal bag HUD variants, multiple maps, no collectibles, target-to-target cycling, blacklist expiry, touch acknowledgement/cache refresh, role-specific round finish, sustained frame time, death/respawn, manual stop, hub unload, and re-execution. Failed paths report failure and never claim confirmed game-controller firing.
